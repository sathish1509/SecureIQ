Frequently Asked Questions

❓ How does SecureIQ calculate the Risk Score?

The risk score (0-100) is generated by aggregating weights from lexical tokenizers (e.g., domain age, TLD risk, hyphen density), TLS certificate validation, IP host detection, and gradient boosted ML model predictions trained on millions of benign and malicious URLs.

❓ What is the difference between URL Scanner and Email Scanner?

The URL Scanner focuses strictly on target link metrics (DNS, protocol, entropy). The Email Scanner inspects RFC-822 header alignment (SPF, DKIM, Reply-To mismatches), social engineering urgency triggers, and embedded links inside emails.

❓ How do I integrate the API into my existing SIEM/SOAR?

Issue an API key from the Settings page and send JSON payloads to POST /analyze with headers Authorization: Bearer YOUR_API_KEY. Returns full JSON telemetry including signals breakdown.
